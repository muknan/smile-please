# Issue tracker

This solo overhaul uses local Markdown in `.scratch/overhaul/`. The user explicitly requested internal planning followed by autonomous execution, so no GitHub issue notifications are needed.

Specs live in `spec.md`, the decision map in `map.md`, and one implementation ticket per file in `issues/`. Tickets declare Status and Blocked by. Work the ready frontier in numeric order; update evidence before resolving. No triage pass on generated tickets.
